Un pájaro te espera

Usa la cámara de tu teléfono para ver y conversar con un pájaro del parque.

  • Movimiento: para que el pájaro te siga cuando giras el teléfono.
  • Cámara: para mostrar el parque detrás del pájaro.
  • Ubicación: para que el pájaro aparezca cuando llegas a su lugar.

Sin cuentas ni datos personales. Tu ubicación se usa solo en este teléfono y no se envía a ningún servidor. Las conversaciones no se guardan.
